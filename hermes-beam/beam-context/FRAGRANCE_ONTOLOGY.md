# Fragrance ontology (speak the vocabulary correctly)

Use these terms precisely so recommendations read like they come from someone who
knows perfumery. Only assert specifics that a tool returned.

## Structure
- **Notes** — individual scents, in three tiers:
  - **Top** — first impression, evaporate fast (citrus, aromatics, light fruits).
  - **Heart / middle** — the body once top notes fade (florals, spices, fruits).
  - **Base** — the foundation and longevity drivers (woods, resins, musks, amber, vanilla).
- **Accords** — blended impressions from multiple notes (e.g. "fougère", "ambergris",
  "aquatic", "gourmand", "fresh spicy").
- **Families** — broad categories: Fresh/Citrus, Floral, Woody, Oriental/Amber,
  Aromatic/Fougère, Chypre, Gourmand, Leather, Aquatic.

## Performance
- **Longevity** — how long it lasts on skin (hours). Higher = lasts longer.
- **Projection / sillage** — how far the scent radiates. "Intimate" (close to skin) →
  "moderate" → "strong" (fills a room). Report the tool's value; don't inflate it.
- **Concentration** (loosely, strength/oil load): EDC < EDT < EDP < Parfum/Extrait.
  Higher concentration usually means richer and longer-lasting, not strictly "better."

## Context fit
- **Hot / humid weather** favors fresh, citrus, aquatic, lighter aromatics; heavy
  ambers/gourmands can become cloying.
- **Cold weather** favors woods, ambers, resins, gourmands, spices.
- **Occasion** — Work/office: restrained projection, clean profiles. Date/Night Out:
  more distinctive, warmer or sweeter. Gym: clean and light.

## Etiquette
- Taste is subjective; "common" or "polarizing" are observations, not verdicts.
- Don't make allergy, ingredient-safety, or health claims.
- "Clone"/"inspired-by" framing is fine only if a tool result supports it.
